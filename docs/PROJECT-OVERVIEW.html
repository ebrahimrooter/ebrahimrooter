۱. خلاصه‌ی پروژه

سیستم پیامک‌های بانک را از روی سیم‌کارت می‌گیرد، واریز و برداشت را تشخیص می‌دهد، از تو می‌پرسد «بابت چی بود؟» (در بله، اپ یا با صدا) و جوابت را در یک حسابداری کامل دوطرفه ثبت می‌کند. همه‌چیز روی سرور خودت است؛ صدای فارسی (تبدیل صدا به متن و متن به صدا) هم محلی روی همان سرور اجرا می‌شود.

📡 دستگاه پیامک

ESP32 + SIM800L؛ پیامک بانک را با اینترنت سیم‌کارت یا وای‌فای به سرور می‌فرستد و هر ۱۰ دقیقه گزارش سلامت می‌دهد.

🖥 سرور

PHP 8 + SQLite روی VPS (Ubuntu) یا هاست اشتراکی یا کامپیوتر خانه؛ تشخیص پیامک، دفاتر، ربات، کارهای زمان‌بندی‌شده.

🤖 ربات بله

خبر واریز/برداشت، پرسیدن «بابت چی بود؟» با متن یا ویس، گزارش‌ها، اعلام صبحگاهی چک‌ها.

📒 حسابداری

۲۹ جدول: فاکتور، انبار، اشخاص، خزانه، چک، وام، مالیات و مؤدیان، پیامک، چند شرکت، کاربران و دسترسی.

📱 اپ آیفون

SwiftUI؛ طرح سبز، گزارش، پنل حسابداری داخل اپ، دستیار صوتی orb، PiP، Dynamic Island، سیری.

🤳 اپ اندروید

Kotlin؛ وب‌اپ داخل اپ + orb شناور روی صفحه‌ی اصلی با کارت پایین صفحه؛ خودش تراکنش تازه را می‌پرسد.

🌐 وب‌اپ و پنل

وب‌اپ گوشی (PWA با نوتیف و orb) و پنل حسابداری روی کامپیوتر؛ داخل هر دو اپ هم هست.

🎙 صدای فارسی محلی

faster-whisper (صدا به متن) و Piper (متن به صدا)؛ برای بله، اپ‌ها و orb.

۲. نقشه‌ی کلی اتصال همه‌ی بخش‌ها و راه ارتباطشان

۳. مسیر یک پیامک بانک، قدم‌به‌قدم

  1. بانک پیامک می‌فرستد«بانک ملت · برداشت: ۲,۵۰۰,۰۰۰ · مانده: … · ۱۴۰۵/۰۷/۱۰-۱۴:۴۷» روی سیم‌کارت داخل SIM800 می‌نشیند.
  2. ESP32 می‌خواندهر چند ثانیه AT+CMGL؛ متن UCS2 را به فارسی برمی‌گرداند؛ فقط فرستنده‌ی مجاز (مثلاً Bank Mellat).
  3. به سرور می‌فرستدPOST api.php?r=ingest با هدر X-Device-Token (با اینترنت سیم‌کارت در gprs_forwarder یا وای‌فای در sms_forwarder). اگر سرور در دسترس نبود، پیامک روی سیم می‌ماند و بعداً می‌رود.
  4. سرور تشخیص می‌دهدنوع (واریز/برداشت/رمز پویا)، مبلغ (ریال)، مانده، تاریخ؛ تکراری را حذف می‌کند (کلید یکتا)؛ تراکنش «منتظر توضیح» می‌سازد. رمز پویا جدا و با PIN نگه داشته و زود پاک می‌شود.
  5. خبر می‌دهدربات بله: «🔴 برداشت … بابت چی بود؟» · نوتیف وب‌اپ (orb مثل سیری) · orb شناور اندروید خودش با صدا می‌پرسد.
  6. جواب می‌دهیتایپ، دکمه، ویس بله یا گفتن به orb؛ صدا روی سرور به متن تبدیل می‌شود؛ دسته و طرف حساب را از جمله حدس می‌زند و تأیید می‌گیرد.
  7. ثبت در حسابداریسند دوطرفه خودکار (بانک ↔ درآمد/هزینه یا حساب شخص)؛ مانده‌ی اشخاص و گزارش‌ها به‌روز می‌شوند.
  8. پایش و گزارشمغایرت‌گیری با مانده‌ی بانک، گزارش هفتگی، یادآوری بی‌جواب‌ها، هشدار قطع دستگاه پیامک (۳۰ دقیقه)، اعلام صبحگاهی چک‌ها.

۸. نقشه‌ی راه نصب از ESP32 تا بله و اپ‌ها

  1. سرور آمادهVPS اوبونتو (۴ گیگ رم، ۲۵ گیگ دیسک) + دامنه (یا IP.sslip.io):
    sudo bash deploy-vps.sh --domain 185-221-237-61.sslip.io
    رمز اپ، DEVICE_TOKEN و آدرس‌ها در پایان چاپ می‌شوند. بدون VPS: هاست اشتراکی (install.php) یا start-windows.bat.
  2. ربات بله آمادهدر بله به @botfather ← ربات بساز ← توکن را در bale_bot_token بگذار ← php cron.php bale-setup ← به ربات /start بده ← chat id را در bale_chat_id بگذار ← دوباره bale-setup.
  3. آزمایش ماژول آمادهLM2596 روی ۴٫۰ ولت · سیم‌کشی جدول بخش ۴ · sim800_test را آپلود کن · در Serial Monitor باید ثبت در شبکه و پیامک‌ها را فارسی ببینی.
  4. اتصال ESP32 به سرور آمادهgprs_forwarder.ino: SERVER_URL، DEVICE_TOKEN، ALLOWED_SENDER و APN را بنویس و آپلود کن. یک پیامک آزمایشی ← باید در بله «بابت چی بود؟» بیاید و در تنظیمات اپ «دستگاه پیامک: فعال» دیده شود.
  5. فرستنده‌ی بانک آمادهبعد از اولین پیامک: وب‌اپ ← تنظیمات ← «فرستنده‌های پیامک» ← فقط شناسه‌ی بانک را تیک بزن.
  6. اپ اندروید نیاز به تست روی گوشیAPK را نصب کن ← آدرس سرور ← رمز اپ ← تنظیمات ← «روشن کردن orb» ← اجازه‌ی نمایش روی برنامه‌ها و میکروفون.
  7. اپ آیفون نیاز به تست روی گوشیروی مک: xcodegen generate ← Team و شناسه‌ی اپ ← Run روی آیفون ← در اپ: آدرس سرور و رمز اپ ← «ورود» (بخش ۱۱).
  8. حسابداری آمادهپنل /bank/acc/ با admin و رمز اپ ← رمز را عوض کن ← مشخصات شرکت، حساب‌های بانک و صندوق، اشخاص، کالاها ← اتصال تراکنش‌های بانک به حساب بانکی.
  9. پشتیبان‌گیری آمادهbackup_password را در config.php بگذار؛ از همان شب خودکار است (بخش ۱۳).
  10. نوتیف اپ آیفون کلید اپل لازم استکلید .p8 از developer.apple.com و چهار خط در config.php (بخش ۱۲).

۱۱. ورود اپ آیفون بدون وب‌اپ مرحله‌به‌مرحله

  1. اپ را باز کنبعد از صفحه‌های معرفی، صفحه‌ی «اتصال به حسابداری» می‌آید. حالت پیش‌فرض «رمز اپ» است.
  2. آدرس سرورهمان آدرس وب‌اپ؛ مثلاً 185-221-237-61.sslip.io/bank. اپ خودش https:// و api.php را اضافه می‌کند. آدرس اینترنتی باید https باشد.
  3. رمز اپهمان رمزی که در وب‌اپ و پنل می‌زنی (app_token) ← «ورود».
  4. چه اتفاقی می‌افتدسرور رمز را چک می‌کند و یک توکن دستگاه می‌دهد که در Keychain آیفون می‌ماند. رمز اپ روی گوشی ذخیره نمی‌شود. در چت بله پیام «گوشی … وصل شد» می‌آید.
  5. امنیت۵ رمز اشتباه از یک آدرس = ۱۵ دقیقه قفل و خبر در بله. هر گوشی را از وب‌اپ ← تنظیمات ← «اپ دستیار آیفون» می‌شود لغو کرد؛ اگر شک داری رمز اپ را هم عوض کن.
  6. راه قبلی هم هست«کد یک‌بارمصرف» از تنظیمات وب‌اپ، برای وقتی نمی‌خواهی رمز را روی آن گوشی تایپ کنی.

۱۲. نوتیف خود اپ آیفون (APNs) مرحله‌به‌مرحله

نیاز: حساب Apple Developer Program (پولی، سالانه). با Apple ID رایگان اپل اجازه‌ی نوتیف نمی‌دهد؛ در آن حالت نوتیف از وب‌اپ یا بله می‌آید.
  1. ساخت کلیدdeveloper.apple.com ← Certificates, IDs & Profiles ← Keys ← «+» ← نام دلخواه ← تیک Apple Push Notifications service (APNs) ← Continue ← Register ← Download. فایل AuthKey_XXXXXXXXXX.p8 فقط یک بار دانلود می‌شود؛ نگهش دار. Key ID (۱۰ حرف) را یادداشت کن.
  2. Team IDdeveloper.apple.com ← Membership details ← Team ID (۱۰ حرف).
  3. شناسه‌ی اپدر Identifiers، شناسه‌ی اپ (مثلاً ir.yourname.bankassistant) را بساز و Push Notifications را تیک بزن. همین شناسه در ios/project.yml و Xcode.
  4. فایل روی سرور
    sudo mkdir -p /etc/bank-assistant
sudo cp AuthKey_ABC123DEFG.p8 /etc/bank-assistant/
sudo chown root:www-data /etc/bank-assistant/AuthKey_ABC123DEFG.p8
sudo chmod 640 /etc/bank-assistant/AuthKey_ABC123DEFG.p8
    (بیرون از پوشه‌ی وب، تا از اینترنت دیده نشود.)
  5. config.php
    'apns_key_id'   => 'ABC123DEFG',
'apns_team_id'  => 'TEAM123456',
'apns_key_file' => '/etc/bank-assistant/AuthKey_ABC123DEFG.p8',
'apns_topic'    => 'ir.yourname.bankassistant',
  6. XcodeSigning & Capabilities ← Push Notifications (در پروژه آماده است؛ فقط Team را انتخاب کن) ← Run روی آیفون.
  7. در اپبعد از ورود، اپ اجازه‌ی نوتیف می‌خواهد ← Allow. در پروفایل اپ «نوتیف تراکنش‌ها: فعال» دیده می‌شود.
  8. آزمایشوب‌اپ ← تنظیمات ← «نوتیف آزمایشی»؛ یا یک پیامک بانک. روی نوتیف واریز/برداشت نگه دار: «بابت چی بود؟» را همان‌جا بنویس ← «ثبت» (بدون باز کردن اپ در دفاتر ثبت می‌شود). یا «جواب با صدا» ← اپ باز می‌شود با همان تراکنش و دکمه‌ی میکروفون.
  9. نسخه‌ی TestFlight / App Storeاین نسخه‌ها خودشان به سرور «production» اپل وصل می‌شوند؛ تنظیم دیگری لازم نیست.

۱۳. پشتیبان‌گیری خودکار مرحله‌به‌مرحله

  1. رمز پشتیباندر config.php: 'backup_password' => 'یک رمز بلند'. فایل‌ها با AES-256 قفل می‌شوند. این رمز را جای امنی جدا از سرور بنویس؛ بدون آن برگرداندن ممکن نیست.
  2. خودکارهر شب از ساعت ۳: همه‌ی پایگاه‌های داده (بانک و همه‌ی شرکت‌ها) یک فایل bank-backup-تاریخ.bkp می‌شوند؛ ۱۴ تای آخر روی سرور (data/backups) می‌مانند (backup_keep) و هر فایل به چت بله‌ی تو فرستاده می‌شود (نسخه‌ی بیرون از سرور). اگر نشد، در بله خبر می‌دهد.
  3. دستیوب‌اپ ← تنظیمات ← «پشتیبان‌گیری» ← «پشتیبان بگیر»؛ همان‌جا هر فایل را دانلود کن. یا روی سرور: php cron.php backup.
  4. برگرداندن
    sudo systemctl stop bank-bot
cd /var/www/html/bank
sudo -u www-data php cron.php restore                       # فهرست پشتیبان‌ها
sudo -u www-data php cron.php restore bank-backup-20261007-030000.bkp 'رمز پشتیبان'
sudo systemctl start bank-bot
    فایلی که از بله دانلود کرده‌ای را هم می‌شود داد (مسیر کامل فایل). داده‌ی فعلی پاک نمی‌شود؛ به data/before-restore-… منتقل می‌شود.
  5. آزمایش کنیک بار روی یک کپی سرور برگرداندن را امتحان کن تا مطمئن شوی رمز را درست داری.
