# دستیار صوتی حساب بانکی

پیامک واریز/برداشت بانک ملت می‌رسد ← گوشی می‌پرسد «بابت چی بود؟» ← جواب می‌دهی «حواله به علی رضایی بابت خرید بذر» ← در دفتر حسابداری ثبت می‌شود ← هر هفته خودکار صورت مغایرت گرفته می‌شود.

```
 پیامک بانک ملت
      │
      ▼
 ESP32 + ماژول سیم‌کارت ──(Wi-Fi / HTTPS)──►  سرور (PHP + SQLite روی همان هاست)
 (یا: شورتکات آیفون / اپ فوروارد پیامک اندروید)      │  ├─ تشخیص واریز/برداشت، مبلغ، مانده، تاریخ
                                                     │  ├─ ربات بله: می‌پرسد، جواب متنی/ویس را می‌فهمد و با ویس جواب می‌دهد
                                                     │  │    (صدا↔متن فارسی روی همین سرور: faster-whisper + Piper، بدون سرویس ابری)
                                                     │  ├─ هشدار اگر دستگاه پیامک از کار بیفتد
                                                     │  ├─ کرون هفتگی: مغایرت‌گیری
                                                     │  └─ ارسال به برنامه حسابداری (Webhook / اکسل)
                                                     ▼
                                     اپ گوشی (PWA): دستیار صوتی + دفتر + مغایرت
```

## اجزا

| پوشه | چیست |
|---|---|
| `firmware/sms_forwarder/` | برنامه ESP32: پیامک‌های روی سیم‌کارت را می‌خواند، به سرور می‌فرستد و فقط بعد از تأیید سرور پاکشان می‌کند (اگر اینترنت قطع باشد، پیامک روی سیم می‌ماند و بعداً فرستاده می‌شود). |
| `server/api.php` | API: دریافت پیامک، لیست بی‌جواب‌ها، ثبت، مغایرت، خروجی اکسل، تبدیل صدا به متن. |
| `voice/` | **صدای محلی:** تبدیل صدا به متن (faster-whisper) و متن به صدا (Piper) فارسی روی خود سرور، بدون API و سرویس ابری. راهنما: [`voice/README.md`](voice/README.md). |
| `server/lib.php` | خواندن پیامک بانک، تاریخ شمسی، زنجیره مانده، مقایسه با صورت‌حساب. |
| `server/bot.php` | گفتگوی ربات بله: سؤال، فهم جواب متنی یا ویس، تأیید با دکمه. |
| `server/cron.php` | گزارش هفتگی مغایرت، یادآوری روزانه، پایش سلامت دستگاه، اتصال ربات بله. |
| `server/app/` | اپ گوشی (مثل اپ مدیریت باغکار، با «افزودن به صفحه اصلی» نصب می‌شود). |
| `server/tests/run.php` | تست خودکار: `php server/tests/run.php` |
| `start-windows.bat` / `start.sh` | اجرای همه‌چیز روی کامپیوتر خودت، بدون هاست |

## دو بخش برنامه 📱💻

- **اپ موبایل (`/bank/app/`):** فقط واریز و برداشت‌ها، موجودی حساب‌ها و دستیار صوتی AI orb. روی orb بزن: اگر تراکنش بی‌جواب باشد می‌پرسد «بابت چی بود؟» و با جوابت ثبت می‌کند؛ وگرنه سؤالت را جواب می‌دهد («موجودیم چقدره؟»، «امروز چقدر واریز شد؟»، «آخرین برداشت»، «این ماه چقدر خرج کردم؟»).
- **پنل حسابداری (`/bank/acc/`):** همه‌چیز؛ از جمله صفحه‌ی «تراکنش‌های بانک» که همان تراکنش‌ها را با امکان جواب دادن و ثبت در دفاتر نشان می‌دهد.
- آدرس `/bank/` خودش گوشی را به اپ و کامپیوتر را به پنل می‌برد.

## نرم‌افزار حسابداری کامل (`/bank/acc/`) 📒

کنار دستیار بانک یک نرم‌افزار حسابداری کامل هم هست، روی همان سرور و همان دیتابیس: `https://دامنه‌ات/bank/acc/`
- **ورود اول:** کاربر `admin` و رمزِ اپ دستیار بانک (`app_token` در config.php). بعد از ورود، در تنظیمات رمز را عوض کن.
- فاکتور خرید/فروش، برگشت، پیش‌فاکتور و سفارش (و تبدیل به فاکتور)، تخفیف درصدی/مبلغی، حمل و گمرک، چاپ فاکتور
- اشخاص، کالا با واحد دوم و بارکد، چند انبار، رسید/حواله/انتقال، انبارگردانی، سریال و بچ، کاردکس
- صندوق، بانک، کارتخوان، تنخواه؛ دریافت، پرداخت، انتقال؛ چک دریافتی/پرداختی (واگذاری، وصول، برگشت، خرج)؛ مغایرت بانکی
- **حسابداری دوطرفه‌ی واقعی:** هر عملیات یک سند با ردیف‌های بدهکار/بستانکار می‌زند (کدینگ کل و معین)؛ تراز آزمایشی، ترازنامه، سود و زیان، دفتر روزنامه، سند افتتاحیه خودکار، سند اختتامیه، قفل دوره
- بهای تمام‌شده با میانگین موزون (تخفیف و هزینه‌ی حمل در بهای کالا)، صورتحساب الکترونیکی سامانه مؤدیان (شبیه‌سازی ارسال)، مالیات بر ارزش افزوده
- کاربران با نقش (مدیر، حسابدار، فروشنده، انباردار)، تاریخچه‌ی فعالیت، پیوست فایل، خروجی Excel، Webhook (n8n)
- **پنل پیامک:** ارسال تکی و گروهی (همه، گروه اشخاص، بدهکاران)، نمونه‌پیامک با {name} و {balance}، پترن کاوه‌نگار و sms.ir، پیامک خودکار فاکتور و یادآوری سررسید چک، تاریخچه و ارسال دوباره
- وام دریافتی و قرض داده‌شده با جدول اقساط و سود، پیش‌دریافت و پیش‌پرداخت، انواع هزینه و درآمد، اسناد ضمانتی (سفته، ضمانت‌نامه)، دسته چک
- تولید با فرمول (مواد اولیه + سربار)، کالای خدماتی، برند، بخش‌ها، بازاریاب و پورسانت، سررسید فاکتور، دفترچه تلفن، چاپ برچسب بارکد، ورود اشخاص و کالا از اکسل (CSV)
- گزارش‌های مدیریتی: فروش/خرید دوره، سود کالاها با چهار روش (میانگین متحرک، FIFO، میانگین تا تاریخ، آخرین خرید)، سود بخش‌ها، کمیسیون بازاریاب‌ها، حساب سررسیدار، خلاصه حساب‌ها، صورتحساب بانک و صندوق، ریز عملیات، برآورد سفارش، کالاهای بدون گردش، فایل معاملات فصلی
- ابزار: ترمیم اطلاعات، فشرده‌سازی دیتابیس، بستن سال مالی
- **سامانه مؤدیان (ارسال واقعی):** امضای صورتحساب با کلید خصوصی و گواهی، رمزنگاری برای سازمان، ارسال، استعلام و ابطال (API نسخه‌ی ۲). در تنظیمات: «ساخت کلید» ← کلید عمومی را در کارپوشه ثبت کن ← گواهی امضا را بارگذاری کن ← شناسه حافظه و کد اقتصادی ← «آزمایش اتصال». شناسه ۱۳ رقمی هر کالا را در کارت کالا بنویس.
- **چند موسسه:** هر موسسه دفاتر و فایل اطلاعات جدا دارد؛ از بالای پنل عوض می‌شود.
- **پشتیبان واقعی:** دانلود کامل فایل اطلاعات و بازیابی از آن (نسخه‌ی قبلی روی سرور نگه داشته می‌شود).
- **اتصال به دستیار بانک:** به‌طور پیش‌فرض روشن است: هر تراکنش تأییدشده در دستیار بانک (پیامک، بله، صدا) خودکار دریافت/پرداخت یا انتقال در دفاتر شود.
- همه‌چیز روی سرور خودت است؛ حتی فونت و اسکریپت‌ها از اینترنت بار نمی‌شوند.

تست‌ها: `php server/tests/acc_audit.php` (ممیزی با اعداد حساب‌شده‌ی دستی: بهای تمام‌شده، مالیات، سود و زیان، ترازنامه، صورتحساب‌ها و فایل‌های CSV)، `php server/tests/acc_test.php` (سناریوی کامل و تراز بودن دفاتر بعد از هر مرحله) و `node server/tests/acc_ui_test.js` (مرورگر).

## حسابداری بازرگانی

برنامه‌ی حسابداری جدا لازم نیست؛ همین سیستم دفتر کامل یک کسب‌وکار کوچک است:

| چه چیزی | کجا |
|---|---|
| **حساب اشخاص** — هر نفر چقدر بدهکار/طلبکار است، صورت‌حساب با مانده‌ی ردیف‌به‌ردیف، فرستادن صورت‌حساب برای طرف | تب «اشخاص»، ربات: `/people` و `/p نام` |
| **فروش نسیه / خرید نسیه** (فاکتور بدون جابه‌جایی پول، با سررسید) | صفحه‌ی هر شخص یا «ثبت» |
| **دریافت و پرداخت** — بانکی خودکار از پیامک، نقدی یا بانک‌های دیگر دستی | دستیار / «ثبت» |
| **هزینه و درآمد** بر اساس دسته، **سود و زیان** هر بازه | تب «دفتر» |
| **موجودی حساب‌ها** (بانک ملت، صندوق نقد، بانک‌های دیگر) و **انتقال** بینشان (مثلاً خودپرداز) | تب «دفتر»، تنظیمات |

**قاعده‌ی مهم — هر دسته یکی از سه نوع است:**
- **👤 حساب شخص** (پرداخت به اشخاص / دریافت از اشخاص): حواله، قرض، تسویه، قسط، علی‌الحساب. مانده‌ی طرف را تغییر می‌دهد و طرف حساب لازم دارد.
- **درآمد/هزینه** (خرید، فروش، حقوق، اجاره…): در سود و زیان می‌آید. اگر طرف حساب هم بگویی، در صورت‌حسابش «نقدی — بدون اثر بر مانده» دیده می‌شود.
- **🔁 انتقال**: بین حساب‌های خودت؛ نه درآمد است نه هزینه.

دستیار از جوابت نوع را حدس می‌زند: «حواله به حسن **بابت خرید بذر**» = خرید نقدی (هزینه)، ولی «حواله به حسن **تسویه**» یا «کارت به کارت به حسن» = حساب شخص. قبل از ثبت همیشه نشانت می‌دهد.

مثال: به رضا ۵ میلیون نسیه فروختی (فروش نسیه ← رضا ۵ م بدهکار، درآمد ۵ م). بعد ۴ میلیون واریز کرد، پیامک آمد، گفتی «رضا بابت طلب» ← رضا ۱ م بدهکار؛ درآمد دوباره حساب نمی‌شود.

**شروع:** در تنظیمات «مانده اول» بانک و صندوق را بگذار، و برای هر کسی که از قبل با او حساب داری «مانده اول» (او بدهکار / من بدهکارم) را وارد کن.

> ⚠️ اگر مشمول **سامانه مؤدیان** هستی، فاکتور رسمی باید با نرم‌افزار/شرکت معتمد مالیاتی صادر شود. این سیستم دفتر داخلی و مدیریت طلب و بدهی است، نه جایگزین آن.

## رمز پویا / یکبار مصرف 🔐

رمزهای پویایی که بانک روی همین سیم‌کارت می‌فرستد هم می‌رسند؛ ولی جدا از بقیه و امن:
- رمز **هرگز به‌صورت متن ساده ذخیره نمی‌شود**: رمزنگاری‌شده نگه داشته می‌شود و بعد از مهلتش (پیش‌فرض ۳ دقیقه، یا همان مهلتی که پیامک می‌گوید) **پاک می‌شود**. از روی سیم‌کارت دستگاه هم بلافاصله پاک می‌شود.
- پیامک رمز با اینکه «مبلغ … خرید» دارد، **برداشت حساب نمی‌شود**.
- دیدنش در اپ (دکمه‌ی 🔐 در صفحه‌ی دستیار) یک **PIN جدا** می‌خواهد (`otp_pin` در config.php). PIN فقط در حافظه‌ی صفحه است و بعد از ۳ دقیقه بی‌کاری قفل می‌شود. ۵ بار PIN اشتباه یعنی ۱۵ دقیقه قفل و یک هشدار در بله.
- در بله فقط می‌آید «رمز رسید» (با مبلغ و پذیرنده)، نه خود رمز. اگر راحتی را به امنیت ترجیح می‌دهی، `otp_to_bale => true` بگذار.
- **مبلغ و پذیرنده را هر بار نگاه کن**: اگر خریدی با آن مبلغ و فروشگاه انجام نمی‌دهی، کسی دارد با کارتت خرید می‌کند؛ رمز را به هیچ‌کس نده.

روال: خرید اینترنتی را شروع کن ← صفحه‌ی 🔐 را باز کن ← رمز چند ثانیه بعد از رسیدن پیامک ظاهر می‌شود ← «کپی».

## مغایرت‌گیری چطور کار می‌کند

1. **زنجیره‌ی مانده (خودکار، هر هفته):** هر پیامک ملت «مانده» را دارد. پس برای هر دو پیامک پشت‌سرهم باید `مانده قبلی ± مبلغ = مانده جدید` باشد. اگر نشد، دقیقاً معلوم است چقدر پول و بین کدام دو ساعت بدون پیامک جابه‌جا شده (پیامک نرسیده، ماژول خاموش بوده، یا کارمزد بی‌پیامک). نیازی به صورت‌حساب بانک هم ندارد.
2. **مقایسه با صورت‌حساب بانک:** صورت‌حساب را از اینترنت‌بانک ملت اکسل بگیر، CSV ذخیره کن و در تب «مغایرت» بده. سه لیست می‌گیری: در بانک هست ولی در دفتر نه (با دکمه «ثبت»)، در دفتر هست ولی در بانک نه، و جورشده‌هایی که هنوز «بابت» ندارند.

## راه‌اندازی

### نصب روی هاست: کاملاً خودکار ☁️ (پیشنهادی)
```
ESP32 ──اینترنت سیم‌کارت──► هاست (برنامه حسابداری) ──► بله: «بابت چی بود؟» ──► جواب تو ──► ثبت
```
کامپیوتر و وای‌فای لازم نیست و دکمه‌ای هم نمی‌زنی.

**۱. خرید هاست:** یک هاست لینوکسی ارزان **ایرانی** بخر (کمترین پلن کافی است؛ کل برنامه چند مگابایت است). قبل از خرید از پشتیبانی بپرس:
- PHP نسخه‌ی ۸ با افزونه‌های **pdo_sqlite**، **curl**، **mbstring** و **openssl** دارد؟
- **SSL رایگان** (Let's Encrypt یا AutoSSL) دارد؟ ربات بله فقط به https وصل می‌شود.
- به `tapi.bale.ai` دسترسی دارد؟ هاست ایرانی معمولاً دارد.

یک دامنه هم لازم است (یا زیردامنه‌ای که هاست می‌دهد).

> 🎙 **ویس فارسی (STT/TTS محلی) روی هاست اشتراکی اجرا نمی‌شود**؛ چون Python، ffmpeg و مدل چندگیگی لازم دارد. برای ویس، برنامه را روی یک **VPS لینوکسی** (حداقل ۲ هسته و ۴ گیگ رم) بگذار و `voice/install.sh` را اجرا کن. بقیه‌ی برنامه روی هاست اشتراکی هم کار می‌کند.

**۲. آپلود:** در کنترل‌پنل (cPanel یا DirectAdmin) ← File Manager، یک پوشه‌ی `bank` در `public_html` بساز و **محتوای پوشه‌ی `server`** را داخلش آپلود کن. می‌توانی zip را آپلود و همان‌جا Extract کنی.

**۳. نصب:** بلافاصله `https://دامنه‌ات/bank/install.php` را باز کن و «نصب» را بزن. رمز اپ، PIN رمز پویا و دو خط برنامه‌ی ESP32 را **یادداشت کن**؛ فقط یک بار نشان داده می‌شوند.

**۴. ربات بله:** اپ (`https://دامنه‌ات/bank/app/`) ← تنظیمات ← «ربات بله». توکن را از `@botfather` بگذار، «اتصال» را بزن، و ظرف ۱۰ دقیقه در بله به ربات `/start` بفرست. ربات خودش تو را به‌عنوان صاحب می‌شناسد. ✅

**۵. ESP32:** برنامه‌ی `firmware/gprs_forwarder` (راهنما در `firmware/README.md`).

**۶. (اختیاری) Cron:** برای هشدار «دستگاه خاموش شده»، در کنترل‌پنل ← Cron Jobs، هر ۱۵ دقیقه:
```
php /home/USER/public_html/bank/cron.php health
```
یادآوری روزانه و گزارش هفتگی بدون cron هم اجرا می‌شوند، چون گزارش ۱۰ دقیقه‌ای ESP32 آن‌ها را راه می‌اندازد.

### نصب روی VPS لینوکسی (با ویس فارسی محلی) 🖥 — با یک دستور
یک سرور ابری/VPS با **Ubuntu 22.04 یا 24.04**، حداقل ۴ گیگ رم و ۲۵ گیگ دیسک بگیر و یک دامنه (رکورد A) را به IP آن وصل کن. بعد روی ویندوز در **PowerShell**:
```powershell
scp .\bank-assistant-local-voice.zip root@IP-سرور:/root/
ssh root@IP-سرور
```
و روی سرور:
```bash
apt update && apt install -y unzip
unzip bank-assistant-local-voice.zip && cd bank-assistant
bash deploy-vps.sh --domain دامنه‌ات
```
`deploy-vps.sh` همه‌چیز را انجام می‌دهد: Apache و PHP، کپی برنامه در `/var/www/html/bank`، https رایگان، ساخت `config.php` با رمزهای تازه، cron، و نصب صدای محلی (۱۰ تا ۲۰ دقیقه). آخرش آدرس اپ، **رمز اپ و PIN** (فقط همان یک بار) و دو خط ESP32 را نشان می‌دهد. اجرای دوباره‌اش (مثلاً برای به‌روزرسانی) رمزها و دیتابیس را نگه می‌دارد.
اگر سرور به Hugging Face دسترسی ندارد: `--models-from` (راهنما در [`voice/README.md`](voice/README.md)). بدون ویس: `--no-voice`.

**بدون دامنه:** فقط `bash deploy-vps.sh` (بدون `--domain`). ربات بله با یک سرویس پس‌زمینه (`bank-bot`) که خودش پیام‌ها را از بله می‌گیرد کامل کار می‌کند، با ویس. اپ روی `http://IP-سرور/bank/app/` باز می‌شود ولی بدون https میکروفون، نوتیف و نصب روی صفحه‌ی گوشی ندارد؛ برای صدا از ویس بله استفاده کن. برای https بدون خرید دامنه: `bash deploy-vps.sh --domain 185-221-237-61.sslip.io` (IP خودت با خط تیره به‌جای نقطه؛ sslip.io این اسم را به همان IP می‌برد). ربات در هر دو حالت با همان سرویس پس‌زمینه کار می‌کند و تغییری لازم ندارد.

### اپ آیفون با AI orb 📱
```
پیامک بانک ← ESP32 ← هاست ──نوتیف──► آیفون: «🟢 واریز 5,000 تومان — بابت چی بود؟»
                                       │ می‌زنی
                                       ▼
                     orb در یک‌سوم پایین صفحه مثل سیری (صفحه‌ی پشتش دست نمی‌خورد): می‌پرسد ← جواب می‌دهی ← «ثبت کنم؟» ← «آره» ← «ثبت شد» و می‌رود
```
**یک‌بار برای همیشه:**
1. در **Safari** آیفون `https://دامنه‌ات/bank/app/` را باز کن ← دکمه‌ی **Share** ← **Add to Home Screen**. از این به بعد اپ را **از همان آیکن** باز کن؛ نوتیف در آیفون فقط برای اپ نصب‌شده کار می‌کند (iOS 16.4 به بالا).
2. با رمز اپ وارد شو. کارت «🔔 دسترسی‌های دستیار» را می‌بینی ← **اجازه بده**: آیفون اول اجازه‌ی **نوتیف** و بعد **میکروفون** را می‌پرسد؛ هر دو را Allow کن.
3. تنظیمات ← «دسترسی‌ها» ← **نوتیف آزمایشی**، بعد اپ را ببند. باید نوتیف بیاید.

از این به بعد هر پیامک بانک: نوتیف می‌آید (حتی وقتی اپ بسته است)، و عدد تراکنش‌های بی‌جواب روی آیکن اپ می‌نشیند. با زدن نوتیف، به‌جای صفحه‌ی اپ فقط orb در یک‌سوم پایین صفحه با نور رنگی دور کادر (شبیه سیری) می‌آید؛ یک بار روی orb بزن (آیفون بدون یک لمس اجازه‌ی صدا و میکروفون نمی‌دهد)، می‌پرسد «بابت چی بود؟»، جوابت را ثبت می‌کند و خودش کنار می‌رود. روی اندروید زیر نوتیف دکمه‌های «🎙 جواب بده» و «بعداً» هم هست.

> **محدودیت iOS:** یک وب‌اپ نمی‌تواند روی صفحه‌ی قفل یا روی اپ‌های دیگر چیزی نشان دهد؛ حتماً با زدن نوتیف باز می‌شود. برای حالتی که **اصلاً اپ باز نشود** و خود سیری بپرسد، از «میان‌بر سیری» پایین استفاده کن.

#### میان‌بر سیری (Siri Shortcut) — بدون باز کردن اپ 🎙
در آیفون، اپ **Shortcuts (میان‌برها)** ← **+** ← اسمش را بگذار `Bank` و این اکشن‌ها را به ترتیب اضافه کن (به‌جای `دامنه` آدرس سرورت و به‌جای `رمز` رمز اپ):
1. **Get Contents of URL** ← `https://دامنه/bank/api.php?r=siri_next` ← Show More ← Headers: `X-App-Token` = `رمز`
2. **Get Dictionary Value** ← `id` (نتیجه را با اسم `ID` ذخیره کن: Set Variable)
3. **Get Dictionary Value** ← `audio_url` از نتیجه‌ی مرحله‌ی ۱ ← **Get Contents of URL** (همان Header) ← **Play Sound**
4. **If** `ID` = `0` ← **Stop This Shortcut** ← End If
5. **Record Audio** ← Start Recording: *Immediately* ← Finish Recording: *On Tap* (یا *After Time* ۶ ثانیه)
6. **Get Contents of URL** ← `https://دامنه/bank/api.php?r=siri_answer` ← Method: **POST** ← Request Body: **Form** ← `id` = `ID` (Text)، `audio` = Recorded Audio (File) ← Header همان `X-App-Token`
7. **Get Dictionary Value** ← `audio_url` ← **Get Contents of URL** (همان Header) ← **Play Sound**

از این به بعد: «**Hey Siri, Bank**» (یا در تنظیمات ← Accessibility ← Touch ← **Back Tap** ← دو ضربه پشت گوشی ← Bank). سیری سؤال را با صدای فارسی سرور می‌پرسد، جوابت را ضبط می‌کند، سرور آن را به متن تبدیل و ثبت می‌کند و «ثبت شد» را می‌گوید؛ هیچ اپی باز نمی‌شود. اگر پیامک بانک **روی خود آیفون** هم می‌آید: Shortcuts ← Automation ← **Message** ← فرستنده‌ی بانک ← **Run Immediately** ← Bank؛ آن وقت با رسیدن هر پیامک، خودش می‌پرسد.
(صدای سرور باید نصب باشد؛ برای آزمایش بدون صدا، در مرحله‌ی ۶ به‌جای `audio` کلید `text` را با یک Text بفرست.)

**صدای فارسی روی آیفون (مهم):** آیفون نه صدای فارسی برای حرف زدن دارد، نه تشخیص گفتار فارسیِ قابل‌اعتماد در Safari. تا وقتی صدای محلی سرور را نصب نکنی، orb سؤال را با یک «دینگ» و متن نشان می‌دهد و اگر حرفت را نفهمید، فرم همان تراکنش را باز می‌کند. برای اینکه orb واقعاً حرف بزند و بشنود، **صدای محلی** را روی سرور نصب کن ([`voice/README.md`](voice/README.md)):
```
sudo voice/install.sh --php-config /path/to/server/config.php
```
تبدیل صدا به متن (faster-whisper) و متن به صدا (Piper) هر دو روی خود سرور اجرا می‌شوند؛ هیچ صدایی به اینترنت فرستاده نمی‌شود و API Key لازم نیست. صداهای تکراری («ثبت شد»، …) روی سرور ذخیره می‌شوند.

> اگر هاست به سرور نوتیف اپل (`web.push.apple.com`) دسترسی نداشته باشد، «نوتیف آزمایشی» خطا می‌دهد؛ در آن صورت از پشتیبانی هاست بپرس. ربات بله هم‌زمان کار می‌کند و نوتیف بله را به‌عنوان پشتیبان داری.

### حالت «ESP32 با اینترنت سیم‌کارت + ربات بله» 📶
ESP32 پیامک بانک را با اینترنت سیم‌کارت مستقیم به ربات بله می‌فرستد (`firmware/bale_direct`، راهنما در `firmware/README.md`). برنامه‌ی کامپیوتر با **همان توکن و شناسه‌ی چت** اجرا می‌شود. وقتی زیر پیام دکمه‌ی «✍️ ثبت در حسابداری» را بزنی یا Reply کنی، برنامه پیامک را ثبت می‌کند، «بابت چی بود؟» را می‌پرسد و در دفتر و حساب اشخاص می‌نشاند. در این حالت ESP32 به وای‌فای و دیدن کامپیوتر نیاز ندارد.

### اجرا روی کامپیوتر خودت (بدون هاست) 💻
کامپیوتر نقش سرور را بازی می‌کند. ESP32 و گوشی باید به **همان وای‌فای** وصل باشند.

**ویندوز:**
1. از [windows.php.net/download](https://windows.php.net/download/) زیر جدیدترین نسخه‌ی PHP 8، فایل ZIP مربوط به **VS17 x64 Non Thread Safe** را بگیر.
2. محتوایش را در پوشه‌ی `php` کنار `start-windows.bat` باز کن، طوری که مسیر `bank-assistant\php\php.exe` وجود داشته باشد.
3. روی **`start-windows.bat`** دوبار کلیک کن. اگر فایروال ویندوز پرسید، **Private networks** را اجازه بده.
4. بار اول خودش `config.php` را با رمزهای تصادفی می‌سازد و در پنجره نشان می‌دهد:
   - رمز اپ و PIN رمز پویا
   - آدرس اپ روی همین کامپیوتر و روی گوشی
   - سه خطی که باید در `sms_forwarder.ino` بگذاری (`SERVER_URL`، `HEARTBEAT_URL`، `DEVICE_TOKEN`)
5. مرورگر خودش باز می‌شود (`http://localhost:8080/app/`). تا وقتی پنجره‌ها باز است سیستم کار می‌کند.

**ویس فارسی محلی روی ویندوز (اختیاری):** بعد از اولین اجرای `start-windows.bat`، در PowerShell از پوشه‌ی برنامه:
```powershell
powershell -ExecutionPolicy Bypass -File voice\install-windows.ps1
.\start-windows.bat              # حالا پنجره‌ی «voice» هم باز می‌شود
.\start-windows.bat voice-test   # در PowerShell دیگر: متن ← صدا ← متن
```
جزئیات: [`voice/README.md`](voice/README.md).

**لینوکس / مک:** PHP را نصب کن (`sudo apt install php-cli php-sqlite3 php-curl php-mbstring` یا `brew install php`) و `./start.sh` را اجرا کن.

نکته‌ها:
- **IP کامپیوتر را ثابت کن** (در تنظیمات مودم، DHCP Reservation)؛ وگرنه اگر عوض شود ESP32 کامپیوتر را پیدا نمی‌کند. البته پیامک‌ها روی سیم‌کارت می‌مانند و گم نمی‌شوند.
- کامپیوتر باید روشن باشد تا پیامک‌ها برسند؛ اگر خاموش بود، بعد از روشن شدن خودشان می‌رسند.
- **ربات بله روی کامپیوتر هم کار می‌کند** (بدون آدرس عمومی، با روش polling). فقط `bale_bot_token` و بعداً `bale_chat_id` را در `config.php` بگذار و برنامه را دوباره اجرا کن؛ `bale-setup` لازم نیست.
- کارهای زمان‌بندی‌شده (گزارش هفتگی، یادآوری، پایش دستگاه) را همان پنجره‌ی «jobs and Bale bot» انجام می‌دهد؛ cPanel لازم نیست.
- **محدودیت گوشی روی شبکه‌ی خانه:** مرورگر گوشی روی آدرس `http://192.168...` (بدون https) اجازه‌ی میکروفون، نصب روی صفحه اصلی و کپی خودکار نمی‌دهد. پس روی گوشی ثبت با تایپ کار می‌کند، و برای **صدا از ربات بله (ویس)** یا از مرورگر خود کامپیوتر (`localhost`) استفاده کن. با هاست و https این محدودیت نیست.
- پایگاه داده (`server/data/bank.sqlite`) را گاهی جایی کپی کن؛ کل حساب‌هایت همین یک فایل است.

### ۱. سرور
1. پوشه `server/` را روی هاست آپلود کن (مثلاً `public_html/bank/`). PHP 7.4+ با `pdo_sqlite` و `curl` کافی است.
2. `config.sample.php` را به `config.php` کپی کن و دو رمز `app_token` و `device_token` را بلند و تصادفی بگذار.
3. پوشه `data/` باید قابل نوشتن باشد (دیتابیس خودش ساخته می‌شود).
4. کرون جاب‌ها در cPanel:
   ```
   0 20 * * 5  php /home/USER/public_html/bank/cron.php weekly
   0 21 * * *  php /home/USER/public_html/bank/cron.php remind
   */15 * * * *  php /home/USER/public_html/bank/cron.php health
   ```
5. برای رمز پویا `otp_pin` را در config.php بگذار (حداقل ۴ رقم، غیر از رمز اپ).

### ۲. اپ گوشی
آدرس `https://your-site/bank/app/` را باز کن ← Share ← Add to Home Screen ← رمز `app_token` را بزن.

### ۳. ربات بله (توصیه‌شده — مخصوصاً برای آیفون)
با ربات، دیگر لازم نیست اپ را باز کنی؛ همه‌چیز در چت بله انجام می‌شود:

```
ربات:  🔴 برداشت 250,000 تومان
       🕓 1405/07/06 18:40 · مانده: 750,000 تومان
       بابت چی بود؟ بنویس یا ویس بفرست.        [⏭ بعداً] [🚫 نادیده بگیر]
تو:    (ویس) «حواله به علی رضایی بابت خرید بذر»
ربات:  📝 بابت: حواله به علی رضایی بابت خرید بذر
       👤 طرف حساب: علی رضایی   📂 دسته: حواله / انتقال به اشخاص
       درسته؟        [✅ ثبت] [📂 تغییر دسته] [👤 بدون طرف حساب] [🚫 نادیده]
تو:    ✅  (یا بنویس «آره»)
ربات:  ✅ ثبت شد … و سؤال بعدی
```

- جواب بی‌Reply مال آخرین سؤال است؛ برای سؤال قدیمی‌تر روی همان پیام **Reply** کن.
- فرمان‌ها: `/pending` سؤال بعدی، `/report` مغایرت ۷ روز اخیر، `/today` خلاصه امروز، `/people` طلب و بدهی اشخاص، `/p رضا` ریز حساب یک نفر.
- اگر دسته «حساب شخص» باشد و اسمی نگفته باشی، ربات می‌پرسد «اسم شخص؟» و بعد از ثبت، مانده‌ی جدید او را می‌گوید.
- فقط chat id خودت جواب می‌گیرد؛ بقیه اگر `/start` بزنند فقط شناسه چت خودشان را می‌بینند.
- **ویس** با صدای محلی سرور ([`voice/README.md`](voice/README.md)) به متن تبدیل می‌شود و ربات **جوابش را هم ویس می‌فرستد** (کنار پیام متنی و دکمه‌ها). بدون نصب آن، جواب را بنویس (کیبورد آیفون میکروفون هم دارد). خاموش کردن ویس جواب: `'bale_voice_reply' => false`.

راه‌اندازی:
1. در بله به `@botfather` پیام بده، ربات بساز و توکن را در `bale_bot_token` بگذار. `api_url` را هم پر کن.
2. یک بار اجرا کن: `php cron.php bale-setup` (ربات را به سرور وصل می‌کند).
3. به ربات `/start` بفرست؛ شناسه چتت را جواب می‌دهد. آن را در `bale_chat_id` بگذار و دوباره `bale-setup` را بزن.

### ۴. ESP32 + SIM800
> 📘 **راهنمای کامل قدم‌به‌قدم، شکل سیم‌کشی و جدول عیب‌یابی:** [`firmware/README.md`](firmware/README.md). اول برنامه‌ی آزمایشی `firmware/sim800_test` را بریز، بعد `firmware/sms_forwarder`.

- **ماژول:** SIM800/SIM800L فقط 2G است. قبل از هر چیز با گذاشتن سیم‌کارت در ماژول ببین چراغ شبکه هر ~۳ ثانیه یک بار چشمک می‌زند (یعنی در شبکه ثبت شده؛ هر ~۱ ثانیه یعنی هنوز دنبال شبکه است). اگر 2G اپراتورت آنجا کار نکرد، **A7670E** (4G) بخر؛ کد بدون تغییر کار می‌کند.
- سرعت ارتباط با SIM800 در کد روی 9600 گذاشته شده که مطمئن‌ترین حالت است.
- **تغذیه (مهم‌ترین نکته‌ی SIM800):** ماژول در لحظه‌ی ارتباط تا ۲ آمپر می‌کشد و با ولتاژ ۳.۷ تا ۴.۲ کار می‌کند. از یک باتری لیتیومی 18650 یا ماژول کاهنده (Buck) تنظیم‌شده روی ۴ ولت بده؛ **نه از پین ۳.۳ یا ۵ ولت ESP32**. یک خازن ۴۷۰ تا ۱۰۰۰ میکروفاراد نزدیک ماژول بین VCC و GND بگذار. زمین‌ها مشترک. اگر ماژول مدام ری‌استارت شد، تقریباً همیشه مشکل از تغذیه است.
- **سیم‌کشی:** TX ماژول → GPIO16، RX ماژول → GPIO17.
- در `sms_forwarder.ino` نام و رمز وای‌فای و سه خطی را که `start-windows.bat` نشان می‌دهد (`SERVER_URL`، `HEARTBEAT_URL`، `DEVICE_TOKEN`) بنویس؛ روی هاست آدرس‌ها `https://your-site/bank/api.php?r=…` می‌شوند و با Arduino IDE (برد ESP32 Dev Module) آپلود کن.
- **سیم‌کارت:** شماره‌ای که پیامک ملت برایش می‌آید باید همین سیم باشد (یا در شعبه/همراه‌بانک این شماره را برای سرویس پیامک ثبت کن).
- **پایش سلامت:** دستگاه هر ۱۰ دقیقه آنتن، وضعیت سیم‌کارت و صف پیامک را گزارش می‌دهد (در تنظیمات اپ دیده می‌شود). اگر ۳۰ دقیقه خبری نشود، سیم‌کارت از شبکه بیفتد یا پیامک‌ها روی سیم جمع شوند، کرون `health` یک بار در بله خبر می‌دهد و وقتی دوباره وصل شد هم خبر می‌دهد.
- **فرستنده‌ی بانک:** پیامک بانک با یک شناسه‌ی حرفی (نه شماره) می‌آید. بعد از اولین پیامک، در اپ ← تنظیمات ← «فرستنده‌های پیامک» همان شناسه را تیک بزن؛ از آن به بعد پیامک‌های بقیه (اپراتور، تبلیغ) اصلاً ذخیره نمی‌شوند. متن پیامک‌های غیربانکی هم حداکثر یک روز نگه داشته می‌شود.

### راه بدون سخت‌افزار (برای شروع یا کنار ESP32)
همان آدرس `ingest` از هر جایی پیامک می‌پذیرد:
- **آیفون:** Shortcuts ← Automation ← Message ← «Message Contains: ملت» ← Run Immediately ← اکشن *Get Contents of URL*: `POST` به `https://your-site/bank/api.php?r=ingest`، هدر `X-Device-Token`، بدنه Form با `text` = متن پیام و `sender` = فرستنده.
- **اندروید:** هر اپ «SMS Forwarder» که به Webhook بفرستد، با همان هدر و فیلدها.

اگر هر دو (ESP32 و گوشی) یک پیامک را بفرستند، سرور تکراری را تشخیص می‌دهد و یک بار ثبت می‌کند.

## دستیار صوتی — واقعیت‌ها
- تب «دفتر» جمع واریز/برداشت و **نمودار هر دسته** را برای ۷، ۳۰، ۹۰ یا ۳۶۵ روز نشان می‌دهد.
- دکمه 🎙 را بزن: می‌گوید «یک برداشتِ ۲ میلیون و ۵۰۰ هزار تومان، ساعت ۱۸:۴۰. بابت چی بود؟»، جوابت را می‌فهمد، طرف حساب و دسته را خودش پر می‌کند، می‌پرسد «ثبت کنم؟» و با «آره» می‌رود سراغ بعدی.
- فرمان‌ها: «بعدی / رد کن» (بعداً)، «نادیده بگیر» (تراکنش شخصی/تکراری)، «تمام» (قطع دستیار).
- هر دسته کلمه‌های کلیدی دارد (در تنظیمات قابل ویرایش). طرف حساب‌ها یاد گرفته می‌شوند: دفعه بعد که بگویی «حسن کریمی»، دسته‌ی قبلی‌اش خودکار انتخاب می‌شود.
- **اندروید + کروم:** تشخیص گفتار فارسی خوب کار می‌کند.
- **آیفون:** سافاری صدای فارسی ندارد (سؤال با «دینگ» و متن نشان داده می‌شود) و تشخیص گفتار فارسی‌اش محدود است. دو راه: میکروفون کیبورد آیفون در کادر «بابت چه بود؟»، یا صدای محلی سرور ([`voice/README.md`](voice/README.md)) — آن‌وقت اپ صدا را ضبط می‌کند، سرور خودش با Whisper به متن تبدیلش می‌کند و با Piper فارسی حرف می‌زند.

## اتصال به نرم‌افزار دیگر (اختیاری)
- **خروجی اکسل:** تب «دفتر» ← «خروجی اکسل (CSV)»؛ ستون‌ها: تاریخ شمسی، نوع (دریافت/پرداخت)، مبلغ ریال، طرف حساب، دسته، شرح.
- **خودکار (Webhook):** اگر `accounting_webhook` را پر کنی، هر تراکنش ثبت‌شده این JSON را POST می‌کند:
  ```json
  {"id":12,"type":"payment","amount_rial":25000000,"date_jalali":"1405/07/06","time":"18:40",
   "date":"2026-09-28","description":"حواله به علی رضایی بابت خرید بذر","party":"علی رضایی",
   "category":"حواله / انتقال به اشخاص","note":null,"account":"1234","balance_rial":75000000}
  ```
  برای حسابفا (که API دارد) یا هر نرم‌افزار دیگر، یک اسکریپت کوچک این JSON را به فرمت آن تبدیل می‌کند — بگو از کدام نرم‌افزار استفاده می‌کنی تا همان را بنویسم.

## نکته‌ها و محدودیت‌ها
- قالب پیامک ملت از روی الگوهای رایج نوشته شده (کلمه‌های واریز/برداشت/مبلغ/مانده، عدد فارسی و انگلیسی، تاریخ `1405/07/06` یا `0706-18:40`). **چند نمونه پیامک واقعی خودت را (با شماره حساب سانسورشده) بفرست** تا تست‌ها را با آن‌ها دقیق کنم.
- پیامک‌های فارسی بلند در مودم چند تکه می‌رسند؛ سرور تکه‌هایی را که در ۳ دقیقه از یک فرستنده برسند و تنها قابل‌خواندن نباشند به هم می‌چسباند.
- رمزها: `config.php` و دیتابیس با `.htaccess` از وب بسته‌اند؛ حتماً HTTPS داشته باش.
- کد ESP32 روی سخت‌افزار واقعی آزموده و کامپایل نشده؛ منطق سرور، ربات (با شبیه‌ساز API بله) و اپ با تست خودکار و مرورگر آزموده شده‌اند.
