ارسال زنده هنوز به سرویس امضا و کلید سازمان وصل نیست؛ این فیلدها برای آماده‌سازی اتصال هستند.

سطح دسترسی نقش‌ها
admin: همه دسترسی‌ها
accountant: حسابداری، خزانه، خرید، فروش، گزارش، مالیات، انبار
seller: فروش، اشخاص، کالا، گزارش
warehouse: انبار و کالا
هنگام ساخت کاربر، نقش را انتخاب کنید. مدیر می‌تواند از API دسترسی سفارشی بدهد.
