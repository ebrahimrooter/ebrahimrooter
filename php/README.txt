PHP for Windows goes in this folder.

1. Open https://windows.php.net/download/
2. Under the newest PHP 8.x, download the ZIP "VS17 x64 Non Thread Safe".
3. Extract its contents HERE, so that php.exe sits directly in this folder:
      bank-assistant\php\php.exe
4. Double-click start-windows.bat

(Linux / macOS: install PHP with your package manager and run start.sh)
