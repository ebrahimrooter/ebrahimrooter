# اپ آیفون (فایل نصبی)

`bank-assistant-iphone.ipa`: اپ کامل آیفون، با صدای فارسی داخل اپ و ویجت‌ها (Live Activity و دکمه‌ی Control Center).
امضا نشده است؛ با **Sideloadly** و Apple ID خودت نصب کن (iTunes و iCloud نسخه‌ی سایت اپل، نه Microsoft Store).

بعد از نصب: «بدون سرور (مستقیم از ESP32)» ← تنظیمات ← «اتصال به ESP32» ← «گوشی دوم، کد تازه…» ← کد اتصال ESP32 را بزن.
تمدید هفت‌روزه: اپ را حذف نکن، همین فایل را دوباره با Sideloadly نصب کن (اطلاعات و کد اتصال می‌ماند).
اگر Sideloadly برای ویجت خطا داد: Advanced options ← «Remove app extensions».

کد اتصال داخل این فایل نیست (مخزن عمومی است).
